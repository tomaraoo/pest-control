# Milpestcon landing page

A static React and Vite landing page for Milpestcon Anay & Pest Control.

## Development

```bash
pnpm install
pnpm dev
```

The site is frontend-only. Contact links use regular phone and email links and do not require a
server.

See [SEO_SETUP.md](SEO_SETUP.md) for the production-domain, Google Search Console, sitemap, and
Google Business Profile setup checklist.
